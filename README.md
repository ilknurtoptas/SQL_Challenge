# SQL Challenge – Employee Database Analysis

This project demonstrates how to design and query a normalized relational database using PostgreSQL. The dataset represents a fictional company's employee information, including departments, roles, salaries, and employee details.

---

## Project Structure

SQL_Challenge/ ├── data/ # Raw CSV data files ├── schema.sql # SQL code to create tables and relationships ├── queries.sql # SQL queries to extract insights └── ERD.png # Entity Relationship Diagram (ERD)


---

## Technologies Used

- PostgreSQL
- pgAdmin
- SQL

---

## Key Features

- **Database Design**: Normalized tables for employees, departments, roles, and salaries  
- **Schema Creation**: Defined primary and foreign keys to establish relationships  
- **Data Import**: Loaded CSV files into corresponding SQL tables  
- **Advanced SQL Queries**: Joins, aggregations, groupings, and subqueries to answer:
  - Who earns the highest salary?
  - Which department has the most employees?
  - What are average salaries by title?
  - And more...
